# Red Harvest source masters

Six original curated ElevenLabs impact recordings generated for this project on
10 September 2026. Prompts are in `scripts/sfx/harvest_impact_sfx.mjs`.
These lossless working masters are authoring inputs, not shipped browser media.

`node scripts/sfx/build_harvest_crunch.mjs` separates each recording into body,
crack and delayed tear, then conforms the resulting six runtime MP3s. Run
`node scripts/build_sfx_manifest.mjs` after rebuilding to regenerate measured
playback ceilings and the runtime pack. No credentials or new generation needed.
