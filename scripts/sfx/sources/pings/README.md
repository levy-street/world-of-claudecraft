# Party ping source masters

Eleven CC0 1.0 recordings from Freesound.org, downloaded as the original
uploads on 26 November 2026 and trimmed here, as mono 44.1 kHz FLAC, to the
stretch each ping layer uses (with margin). These lossless working masters are
authoring inputs, not shipped browser media.

`node scripts/sfx/build_ping_sfx.mjs` layers them into the five `ui_ping_*`
cues by the recipes in `scripts/sfx/ping_sfx.mjs`, levels each to the same true
peak and conforms them as custom masters. Run
`node scripts/build_sfx_manifest.mjs` afterwards. No credentials or network.
