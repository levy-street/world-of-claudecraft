# World quest puzzle preview

Development-only fixture using the current puzzle windows and styles. Run
`npm run dev` and open `/scripts/world_quest_preview/index.html?board=candy`
or `?board=ley` on that server. The toolbar includes explicit effect/outcome
samples. Ley defeat is a design preview only; gameplay has unlimited rotations.

See `docs/screenshots/world-quest-puzzle-polish/README.md` for the full handoff,
recordings, layout options and design evidence.
