A field guide to world quests

The current catalogue contains 20 world quests. The realm offers five at a time, advancing to the next set every three days.

Based on the local design checkout for PR #3847. This briefing describes that implementation, not a live realm status feed.

How it worksQuest catalogueRotation setsPuzzle layouts

One shared realm schedule

Availability, player progress and puzzle layouts follow related but distinct rules.

Available from level 10

Entering an offered quest's marked area starts the quest. Puzzle boards open by interacting with their game box or ley cache.

Three-day offers

The realm follows fixed calendar windows. Logging in does not give a player a fresh three-day timer.

One reward per character, per cycle

Completion grants the reward automatically. The same quest can reward the character again when it appears in a new rotation.

Progress resets at the boundary

The previous cycle's quest progress clears when the next rotation starts, including when a quest appears in consecutive sets.

Reset time: rotation changes use the realm's 3 AM reset clock. The server default is US Eastern; each realm can configure its timezone. The offline game uses the player's local 3 AM reset clock.

Nine sets, a 27-day roster loop

Each set offers exactly five quests for three days. After Set 9, the roster returns to Set 1. Selection is fixed, not random.

The day ranges below show position within a roster loop. They are not a countdown or a claim about which set is live today. The schedule is anchored to the realm reset day of 31 August 2026.

Three-day availability. Weekly layout selection.

The “Weekly level” label on a puzzle board describes its layout schedule. It does not mean the world quest remains available for a full week.

The offer decides what is available

The three-day rotation selects which five quests the realm offers. The nine-set roster repeats every 27 days.

The weekly index selects the layout

Confection Cascade, Ley Beam Alignment and shipwreck salvage each have three authored layouts. Selection uses the weekly slot at the beginning of the three-day offer, and stays fixed throughout that offer.

Example: if a new weekly slot begins while an offer is still active, an unfinished board keeps the layout assigned to that offer. The board does not change halfway through the three-day window.

The 27-day repeat applies to the quest roster, not necessarily to the combination of roster and puzzle layouts. Arcane Calligraphy's advanced rune is selected separately from its rotation cycle.

Ley design note: Ley Beam Alignment currently permits unlimited rotations and has no gameplay losing condition. The new defeat screen is a labelled design preview for the team to connect later.
