# Weekly Vault preview in Groups

The `groups-*`, `after-*`, and `forced-colors-*` images show the release/v0.45.0
Groups and Weekly Vault painters with the production styles and fixture world data.
They are UI harness captures, not a connected multiplayer session. Desktop is
1440x1000, mobile portrait 390x844, and mobile landscape 844x390.

The fixture is a level-60 Holy Paladin with no recorded boss unlocks and one
unclaimed week. Keyboard Enter opens the Vault destination and its possible-loot
catalog. The catalog includes future unlocks while retaining level and loot-focus
filters. Claim and focus controls are absent. Forced-colors captures use Chromium's
forced-colors emulation.

The two `before-*` images are the original PR's historical v0.44.x screenshots;
they do not represent the newer Groups screen on release/v0.45.0.
