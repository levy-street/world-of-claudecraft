# Subscription component fixtures

The before images show the default disabled state (no subscription card). The
after images render the actual `StoreSubscription` component with a synthetic
available, unsubscribed account and the shipped styles. These are isolated store
section fixtures, not a live billing session or an authenticated full-store test.

Captured in Chromium at desktop, mobile portrait and mobile landscape sizes.
The fixture was checked for horizontal overflow and visually inspected. No Stripe
request, purchase, or live account modification was performed.
