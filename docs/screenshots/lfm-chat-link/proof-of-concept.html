How it works

  • The advert posts a small token, [[g:<listingId>]], beside the item [[i:id]] and quest [[q:id]] links that chat already parses.
  • Each client builds the label itself from the listing, so it shows in the reader's language and cannot be faked.
  • Clicking calls a new IWorld action that opens the Groups window on that listing, offline and online.
  • The card always loads the listing's current state: members, open roles, full or closed.
  • Discord keeps the plain text line, since it cannot open the game.
