# Moot Rolls quest-object icon paintings

Original artwork for the two quest objects of the Quartered Isle's history line, The Moot
Rolls (`src/sim/content/quartered_isle_story.ts`).

| Item | Shipping asset | Bytes |
| --- | --- | --- |
| Council Inscription | [WebP](../../../public/ui/items/council_inscription.webp) | 2406 |
| Colossus Maker's Mark | [WebP](../../../public/ui/items/colossus_makers_mark.webp) | 2882 |

Generated with gpt-image-2 (an image edit with two shipped quest-object icons, the Sprung Fen
Trap and the Ember Cache, attached as style references only), one painting per item, then
downscaled to a 512 master and the 128 px shipping WebP. The [provenance record](accepted-art.json)
keeps the exact prompts, reference and output hashes, processing and review. Original PNGs and
512 masters stay in the ignored `tmp/imagegen/quartered-isle-moot-rolls/`.

[Size review](../../screenshots/item-art-consistency-2026-08-09/quartered-isle-moot-rolls-icons-2026-11-19/size-review.png): rows
are the Council Inscription and the Colossus Maker's Mark; columns are 512, 128, 40, 28, 22,
28 grayscale and 64 circular.
