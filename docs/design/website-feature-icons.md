# Website feature icons

Created with the built-in OpenAI image generation tool, then optimized to 192px
WebP while preserving the generated alpha. Both are decorative beside existing
localized labels, rendered at 52px without the former circular containers.

- `public/website-feature-classes-v1.webp`: class crest, shield, sword and staff.
- `public/website-feature-open-v1.webp`: open spellbook.

## Class icon prompt

Use case: stylized-concept. Create one premium fantasy game UI icon for World of ClaudeCraft, representing 'Nine classes, three roles'. A compact heroic gold-edged steel shield with a blue inset gem, a sword and a small mage staff crossing behind it. Refined hand-painted stylized 3D MMORPG item artwork, chunky readable silhouette, faceted steel, warm antique gold, tiny electric cyan accents matching a magical stone portal. Single isolated object, centered, fills 82 percent of square canvas, 1024x1024. Genuinely transparent background with clean alpha edges. No medallion container, no circular border, no ground, no scene, no lettering, no numbers, no logo, no black outline or black backdrop. Must remain clearly legible as a 48px website feature icon.
