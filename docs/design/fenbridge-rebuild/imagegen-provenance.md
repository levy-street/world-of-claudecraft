## Source policy

The user supplied one concept image during the request. Its rights status is not asserted
by this repository, so the source image is not committed. It is used only for broad mood,
weather, palette, material language, and elevated-composition inspiration at the user's
direction. The generation prompt explicitly forbids copying its town plan, silhouettes,
ornaments, symbols, or props.

All checked-in reference turnarounds and shipping geometry must be newly generated for this
project or procedurally authored in this repository. No readable text, copied logos,
watermarks, or third-party franchise symbols are admitted.
