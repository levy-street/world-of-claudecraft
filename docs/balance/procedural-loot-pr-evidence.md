# Procedural Loot PR Evidence

## Scope

This change adds server-authoritative procedural equipment drops while preserving
the authored loot tables.

Nythraxis uses the same drop-first product contract:

- one shared procedural corpse item on Normal
- one shared procedural corpse item on Heroic
- Need/Greed through the existing party-loot system
- smart-loot class weighting from the permanent encounter contribution roster
- difficulty-specific rarity and item-level profiles
- natural Heroic Raid-forged Legendary rolls

The raid has no personal progress currency, Heroic Mark payout, Deathless Forge,
deterministic purchase path, or Legendary tuning action.

## Runtime ownership

The authoritative simulation chooses the source profile and generates the full
procedural payload. Network clients send loot-roll intent only. They cannot
submit a rarity, item level, affix, power, or rolled value.

Nythraxis final-boss death follows this sequence:

1. Resolve ordinary authored loot.
2. Generate one shared procedural item from the selected raid profile.
3. Add the exact copy to the corpse loot container.
4. Open the existing party-loot roll.
5. Apply the difficulty-scoped raid lockout.

No currency settlement or reward mail runs in that sequence.

## Balance pins

| Difficulty | Rare | Epic | Legendary | Rare iLvl | Epic iLvl | Legendary iLvl |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Normal | 65% | 33% | 2% | 27 | 28 | 32 |
| Heroic | 40% | 55% | 5% | 31 | 32 | 36 |

Heroic natural Legendary items retain the Raid-forged drop trait. Their power
magnitude is constrained to the upper half of the authored range.

## Persistence and presentation

Procedural identity, affixes, name data, Legendary power, and roll magnitude
survive bags, equipment, bank, trade, mail, reconnect, and persistence.

The UI presents rarity art, generated names, item level, affixes, Legendary
power text, advanced roll ranges, and the Heroic Raid-forged state. The Dungeon
Finder describes the shared drop, rarity table, item levels, signatures, and
Heroic drop trait without advertising currencies or a redemption service.

## Automated evidence

Core coverage includes:

- deterministic generator and distribution tests
- Nythraxis profile and natural-drop tests
- smart-loot and Need/Greed tests
- item validation and UID uniqueness checks
- bank, trade, mail, reconnect, and persistence integration tests
- offline and online IWorld parity
- generated localization checks
- the repository-wide `npm run gate`

Visual evidence is generated by:

```powershell
npm run procedural:gallery
```

Forge and tuning screenshots are intentionally absent because those product
surfaces are not part of the loot-only design.
