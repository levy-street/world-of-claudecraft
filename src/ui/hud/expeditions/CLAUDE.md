# Open dungeon expeditions

This domain owns the bell, horizontal group cards, entry choice and leader
requests. Read src/ui/CLAUDE.md and src/ui/hud/CLAUDE.md for shared contracts.

The controller reads IWorld only. The view is DOM-free. Poll from the medium
HUD band; never add a repeating driver. An unchanged signature does no DOM work.
Automatic prompts never move focus and stay suppressed during combat. User
opens use the shared window focus bridge. Claim IDs key local entry choices;
they never become client-selected travel destinations.
